# 🔷 Logic Gates Design using Verilog HDL

## 🎯 Objective

To design and simulate basic logic gates such as AND, OR, NOT, NAND, NOR, XOR, and XNOR using Verilog HDL.

## 📝 Description

This project demonstrates the implementation of fundamental digital logic gates. The outputs were verified using simulation and waveform analysis in EDA Playground.

## ✨ Features

* AND Gate
* OR Gate
* NOT Gate
* NAND Gate
* NOR Gate
* XOR Gate
* XNOR Gate

## 🛠 Tools Used

* Verilog HDL
* EDA Playground
* Icarus Verilog
* EPWave

## 📂 Files Included

* Main Verilog Code
* Testbench Code
* Output Screenshots
* Waveform Screenshots

## 📊 Output

Simulation results verified the correct functionality of all logic gates according to their truth tables.
